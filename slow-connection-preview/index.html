A simplified loading model

Office Wi-Fi: file size × 25 milliseconds.
Simulated 3G: file size × 250 milliseconds.

Text loads instantly. Media loads independently. Device width changes the layout, not the timing.

This is a teaching model. It does not measure your connection or compress real files. Lesson clarity must still be checked in a real course.
